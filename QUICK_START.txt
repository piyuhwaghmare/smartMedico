✅ STEP 4: TEST IT
──────────────────────────────────────────────────────────────

What happens:
  1. Agent analyzes symptoms ✓
  2. Agent searches PubMed ✓

📚 NEED HELP?
──────────────────────────────────────────────────────────────

Full setup guide:     MEDICAL_SETUP.md
All changes:          CHANGES_SUMMARY.md
Project description:  README.md

Common issues:
  ❌ "Connection refused" 
     → Check if Ollama is running
     → Check agents/config.py OLLAMA_BASE_URL
  
  ❌ "PubMed rate limit"
     → Get free API key from https://www.ncbi.nlm.nih.gov/account/
     → Set: set PUBMED_API_KEY=your_key
  
  ❌ Modal not showing
     → Open browser console (F12)
     → Check for JavaScript errors
     → Refresh page


🔗 API ENDPOINTS
──────────────────────────────────────────────────────────────

Medical query:
  POST http://localhost:8000/api/medical/stream
  Body: {"message": "symptoms...", "thread_id": "optional"}

Resume after doctor review:
  POST http://localhost:8000/api/resume/{thread_id}
  Body: {"choice": "Accept" or "Reject - reason"}

Get feedback history:
  GET http://localhost:8000/api/threads/{thread_id}/feedback

API docs (Swagger):
  http://localhost:8000/docs
